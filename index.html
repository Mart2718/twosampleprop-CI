How it works

Decide which group is Group 1

Art of Stat always computes Group 1 − Group 2. The order you enter the groups decides the sign of the answer.

Peer Coach first:
p₁ − p₂ = 0.750 − 0.641 = +0.109
Positive: the Peer Coach group is higher.
No Peer Coach first:
p₁ − p₂ = 0.641 − 0.750 = −0.109
Negative: the same fact, said the other way.

Both orders are fine. Use the order the problem gives, and say it in your interpretation.

2-Proportion Z-Interval

Categorical · 2 groups

You need: number of successes (x) and sample size (n) for each group.

  1. Open Compare Two Proportions ↗. Click the Confidence Interval & Significance Test tab.
  2. Under Enter Data, choose Number of Successes. This is for summarized data, which is what we use in class. (Individual Observations is only for raw data.)
  3. Type the Group 1 name, number of successes, and sample size. Then do the same for Group 2.
  4. Under Type of Inference, choose Confidence Interval.
  5. Under Type of Interval, choose Wald. This is our course standard.
  6. Type the Confidence Level (%) as a whole number, such as 95.
  7. Read the Lower Bound and Upper Bound. They are on the proportion scale, so 0.0523 means 5.23 percentage points.

2-Sample T-Interval

Quantitative · 2 groups

You need: mean (x̄), standard deviation (s), and sample size (n) for each group.

  1. Open Compare Two Means ↗. Click the Confidence Interval & Significance Test tab.
  2. Under Enter Data, choose Summary Statistics. This is what we use in class. (Your Own is only for raw data.)
  3. For each group, type the name, sample size, sample mean, and standard deviation. Group 1 goes first.
  4. Under Type of Inference, choose Confidence Interval. Keep it Two-Sided.
  5. Leave the equal variances box unchecked.
  6. Type the Confidence Level (%), such as 95.
  7. Read the Lower Bound and Upper Bound. The degrees of freedom may be a decimal like 80.88. That is normal for this method.

How it works: what Art of Stat is computing

Every interval has the same shape: estimate ± (critical value) × (standard error).

(p̂₁ − p̂₂) ± z* · √[ p̂₁(1−p̂₁)/n₁ + p̂₂(1−p̂₂)/n₂ ]
(x̄₁ − x̄₂) ± t* · √[ s₁²/n₁ + s₂²/n₂ ]

z* is 1.645, 1.960, or 2.576 for 90%, 95%, or 99%. The t* value depends on the degrees of freedom, which Art of Stat finds for you.

How it works: connect to hypothesis tests (Unit 11)

Proportions use a different standard error for intervals and tests. An interval estimates p₁ − p₂, so it uses each group’s own p̂ (unpooled). A test assumes H₀: p₁ = p₂, so it combines both groups into one pooled proportion, p̂ = (x₁ + x₂) / (n₁ + n₂).

Means use the same unpooled standard error for both. Art of Stat’s two-sample t-interval and t-test both use s₁²/n₁ + s₂²/n₂.

Intervals and two-sided tests agree. If a C% interval for the difference does not contain 0, a two-sided test at α = 1 − C would reject H₀: no difference. If 0 is inside the interval, that test would not reject.
